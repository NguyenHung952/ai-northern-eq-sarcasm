# Knowledge Base

Đây là bộ PDF knowledge base dùng để tra cứu cho engine.

## Thứ tự module

| File | Vai trò |
| --- | --- |
| `00_INDEX_NORTHERN_EQ_SARCASM.pdf` | Bản đồ toàn bộ knowledge base |
| `01_NORTHERN_VIETNAMESE_STYLE.pdf` | Giọng Bắc, nhịp câu, understatement |
| `02_HIGH_EQ_SARCASM_ENGINE.pdf` | EQ, sarcasm level, logic counter, behavioral mirror |
| `03_RESPONSE_MODES_AND_ARCHITECTURE.pdf` | Pipeline, social moves, candidate engine |
| `04_ANTI_PATTERNS_AND_BOUNDARIES.pdf` | Guardrails, boundary, escalation control |
| `05_RESPONSE_EXAMPLES.pdf` | Ví dụ kiểm tra style |

## Quy tắc

- Số đầu file biểu thị thứ tự đọc.
- PDF là artifact đầu ra; nội dung source/generator nằm ở `scripts/build_pdfs.py`.
- Không đặt file nháp hoặc file lạ vào thư mục này.
